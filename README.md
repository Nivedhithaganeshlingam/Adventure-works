# 📊 Adventure Works Sales Analysis using Power BI

## 📌 Project Overview

The **Adventure Works Sales Analysis** project is an interactive Power BI dashboard created to analyze sales performance, customer behavior, product performance, and business trends. The project uses the Adventure Works dataset to transform raw business data into meaningful insights through data cleaning, modeling, DAX calculations, and interactive visualizations.

The dashboard helps users understand overall business performance and identify important trends across products, customers, territories, and time periods.

## 🎯 Objectives

* Analyze overall sales and revenue performance.
* Track important business KPIs.
* Identify top-performing products and categories.
* Analyze customer purchasing behavior.
* Compare sales performance across different regions.
* Study sales trends over time.
* Build an interactive and user-friendly business dashboard.

## 🧹 Data Preparation

Power Query was used to clean and transform the Adventure Works dataset.

Key data preparation activities included:

* Removing unnecessary columns
* Handling missing values
* Changing data types
* Cleaning and transforming data
* Creating required columns
* Combining and preparing tables for analysis

## 🗂️ Data Modeling

A structured data model was created in Power BI by establishing relationships between relevant tables.

The model helps connect information related to:

* Customers
* Products
* Sales
* Territories
* Dates
* Product Categories
* Product Subcategories

This enables efficient analysis across different business dimensions.

## 🧮 DAX Calculations

DAX was used to create calculated measures and support dynamic analysis.

Example measures include:

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Customer Count
* Average Sales
* Sales Growth
* Year-to-Date Sales
